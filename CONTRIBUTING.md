# Contributing

Start with one useful claim or package. Link a primary source, or include a redacted reproduction record. Label community reports and hypotheses explicitly.

Keep summaries short and put procedure detail in the relevant guide. Include minimum requirements only when known. Preserve negative results and version differences.

Shortcut submissions need the actual export or legitimate author-provided share link, a contract, dependencies, permissions, fixtures, and evidence. Respect original authorship and licensing. Never upload credentials, private records, or personal stored state.

Tooling changes should pass the documented tests. Device tests must be marked not-run when unavailable; desktop tests do not verify iOS behavior.
