METHOD 1 — shortcuts.open_url

When request.method is exactly:
shortcuts.open_url

Read:
request.params.url

Behavior:
1. If url is empty, return a structured error with code missing_url.
2. Use Apple’s native “Open URLs” action on that URL. Do not use Safari, a-Shell, shell commands, clipboard, or “Open App”.
3. If execution continues after Open URLs, return a dictionary equivalent to:
   {
     "ok": true,
     "result": {
       "opened": true,
       "url": <the requested URL>
     }
   }
4. Feed that result into the worker’s existing completion mechanism using the current request ID.
5. Do not show notifications, Quick Look, alerts, confirmation prompts, or Ask Each Time.

METHOD 2 — shortcuts.run

When request.method is exactly:
shortcuts.run

Read:
request.params.name
request.params.input

Behavior:
1. If name is empty, return a structured error with code missing_name.
2. Use Get My Shortcuts.
3. Find/filter the returned Shortcuts where Name is exactly request.params.name.
4. If no Shortcut matches, return a structured error:
   {
     "ok": false,
     "error": {
       "code": "shortcut_not_found",
       "name": <requested name>
     }
   }
5. If exactly one Shortcut matches, use the native Run Shortcut action on that Shortcut, passing request.params.input as the Shortcut input.
6. Return the child Shortcut’s actual output through the worker’s existing completion mechanism.
7. Do not use a shortcuts:// URL for execution.
8. Do not open the Shortcuts editor or show any UI.
