# Examples

Examples translate the research documents into concrete, inspectable architectures without claiming production/device validation.

| Example | Demonstrates | Status |
|---|---|---|
| [Adaptive Capture Router](adaptive-capture-router/) | Batched typed decisions, confidence gating, frontier-model choice elevation, bounded autonomous loop, post-action verification, iOS mapping | research example; optional real Laya adapter |

Examples should be useful as executable reference code while keeping external side effects safe or mocked until the experiment/release phases. A runnable example is not evidence that the corresponding iOS/runtime integration has been reproduced.
